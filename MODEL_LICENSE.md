# Model artifact licensing

The source-code license and model-artifact license are separate decisions.

## Current status

**No model-weight license has been selected. No official model weights are published from this documentation baseline.**

The root MIT License applies to eligible repository software. It must not be interpreted as automatically licensing trained weights, datasets, third-party tokenizer assets, benchmark datasets or external code samples.

## Release gate

Before distributing trained weights, the project maintainer must choose and document an explicit model license. The decision must account for training-source rights, dataset terms, attribution, intended commercial/non-commercial use, redistribution, derivative models and applicable platform policies.

Each release must carry an unambiguous license identifier or a clear statement that redistribution is not authorized. Do not publish weights while this decision is unresolved.
