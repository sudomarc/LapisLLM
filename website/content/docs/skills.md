# Skills

Lapis skills are versioned, reviewable workflow packages. The website exposes the skill catalogue from `website/data.js` and enriches entries from their normative `SKILL.md` files.

Each skill should define its purpose, inputs, outputs, workflow, limitations, and safety boundaries. Skills are developer/research tooling; they do not change the Lapis consumer-product boundary.

The current catalogue contains ten experimental skills spanning security, development, research, documentation, data, evaluation, and productivity. Their status is descriptive and does not imply production readiness.
