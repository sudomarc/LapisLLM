01 / THE PROJECT

Not a wrapper.
A model.

LAPIS is being engineered as a real language-model stack rather than a thin interface over someone else's model. The first releases are intentionally small: the objective is to make every layer understandable, reproducible and extensible.

01

Own the stack

Model, tokenizer, training loop and inference remain first-class LAPIS components.

02

Scale deliberately

Start with a tiny model, then increase data, compute and capacity without rebuilding the foundation.

03

Measure honestly

Every benchmark, metric and capability claim should be backed by an actual experiment.
