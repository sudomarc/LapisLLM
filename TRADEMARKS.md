identified by the GitHub account `sudomarc`.

The open-source license for the source code does **not** grant permission to
use the LapisLLM name, logo, domain names, or other project branding in a way
that suggests official status, sponsorship, endorsement, or origin.

## Permitted use

You may use the name **LapisLLM** to accurately refer to this upstream
project, for example:

- "Built with LapisLLM"
- "A fork of LapisLLM"
- "Compatible with LapisLLM"

## Restricted use

Do not:

- publish a modified project as the official LapisLLM release;
- use the LapisLLM name or logo for a fork in a way that implies it is
  maintained or endorsed by the project owner;
- register confusingly similar project names, domains, or social accounts;
- remove or alter trademark and attribution notices from official
  distributions.

Forks should use a distinct product name while clearly stating their
relationship to LapisLLM.

## Official releases

Only releases published from the official `sudomarc/LapisLLM` repository and
its authorized release channels are official LapisLLM releases.
